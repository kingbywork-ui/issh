终端不是主题的容器，
是材料的延伸。

Tabby 的皮肤是 Electron 里的一块 CSS；issh 的皮肤是 Tauri WebView2 的 chrome 着色 + Rust isshd 驱动的 xterm 调色板。同一套 Theme + TerminalColorScheme，在新架构里分两层生效 — 我们为此做了 4 套可直接发独立仓库的皮肤。

主题：issh 终端皮肤商城
受众：在 SSH 里生活的人 · 运维 / 开发 / 现场工程师
单一任务：30 秒内挑中一套并一键安装到 issh
审美锚点：服务器机房、纸带、CRT、光纤 — 而非通用的奶油色/酸绿模板
上架：4 套独立仓库 0.1.0 已 vite build → --force-local tgz 封包（Foundry/Field/Phosphor/Void）

架构差异 · 为什么不能直接搬 Tabby 皮肤

Tabby (eugeny/tabby)issh (new-ssh / Tauri)
宿主Electron + AngularTauri 2 + Svelte 5 + Rust isshd
主题入口Theme (css string) + TerminalColorSchemeProvider同接口（issh-core 仍是 Angular JIT），但分两层：WebView2 chrome 与 xterm 画布
样式生效注入 Electron rendererWebView2 的 CSS 变量 --body-bg / --theme-bg-* + --bs-* 控制标签栏/标题栏
终端生效xterm 16 色 + bg/fg/cursor相同，但通过 issh-terminal 的 colorSchemes / config.terminal.colorScheme
分发npm / 内置 issh-community-color-schemes (150+ Xresources)独立 GitHub 仓库 1 仓库 = 1 皮肤 → Release tgz → registry index.json → jsDelivr
安装位置Electron app/plugins%APPDATA%/issh/plugins/<id>/
followsColorScheme = false 精调皮肤followsColorScheme = true 跟随系统

把“机房的材料”
搬进主题变量

不用通用的奶白/酸绿。4 套皮肤各自锚定一种真实材料 — 钢、牛皮纸、荧光粉、光纤 — 并让它贯穿 shell chrome 与终端调色板。标签栏的哑光、选中态的信号色、滚动条的质感，都来自同一种材料逻辑。克制，只赌这一次。

独立仓库骨架 (每套皮肤一个 repo, 参照 issh-plugin-agent-bridge)
issh-plugin-theme-foundry/
├─ package.json (name, version, issh.plugin)
├─ src/index.ts → NgModule 提供 Theme + TerminalColorSchemeProvider
├─ src/theme.scss → 编译后注入 Theme.css
├─ src/colorScheme.ts → foreground/background/cursor + 16 色
└─ plugin.yaml → 商城元数据
发布: build → tgz → gh release → registry/index.json → purge jsDelivr
— 点击色块复制 hex · 终端可交互切换配色

如何把一套皮肤发到 issh 商城 — 独立仓库流水线

每套皮肤 = 一个 GitHub 仓库（与 Tabby 的社区包不同，issh 商城推荐 1 皮肤 1 仓库，便于版本与签名）。Tauri 皮肤为 kind: appearance 自含 Svelte runtime，经 gateway.ui: registerSettingsTab + registerTerminalDecorator 双层注入（chrome CSS 变量 + xterm 16 色 + selection）。

01 — 克隆模板

复制 plugins/issh-plugin-agent-bridge 结构，改 package.json 的 name/version 与 src/index.ts 的 Theme/ColorScheme。深色设 followsColorScheme:false 精调，浅色可设 true 跟随系统。

02 — 构建与签名

npm run build → dist/index.js，node scripts/publish-plugin.mjs <id> 自动打 tgz、算 sha256、ed25519 签名。

03 — 发版与上架

推独立仓库 main + tag v0.x.0 → gh release create 上传 tgz → 更新 kingbywork-ui/issh-plugin-registry/index.json 的 version/downloadUrl/sha256 → purge.jsdelivr.net。

Token 系统（每套皮肤 6 色锚点）：bg / fg / cursor / accent(ANSI 4) / selection / chrome(bg-more)。
