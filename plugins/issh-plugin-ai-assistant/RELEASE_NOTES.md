# issh AI 助手 v0.2.0

## Highlights

- 为 issh Tauri 桌面端提供独立的右侧 AI 助手面板。
- 支持 OpenAI 兼容与 Anthropic 格式的流式回答，以及本地 stdio MCP 工具调用。

## Notes

### AI 对话与终端

- 支持多模型服务商、命令生成与解释、错误分析和按终端保存对话。
- 可选择发送脱敏后的最近终端输出；生成命令只插入终端，不自动执行。

### MCP 工具

- 可配置本地 stdio MCP 服务，列出工具并交给模型调用。
- 每次调用由 issh 宿主显示服务、工具和参数供确认，并限制工具调用轮数。

### 兼容性

- 需要支持插件网关 API v2 的 issh 客户端；旧客户端会在加载前拒绝本插件。
- 插件包不内置模型凭据或 MCP 服务程序。
