# issh AI 助手 v0.2.1

## Highlights

- 新增远程 MCP 服务连接：支持 Streamable HTTP 与旧版 SSE，原仅支持本地 stdio。
- 模型供应商设置与 MCP 服务设置拆分为独立页面，互不干扰。

## Notes

### MCP 工具

- 新增连接方式选择：本地命令（stdio）、远程 Streamable HTTP、远程 SSE（旧版）。
- 远程方式填写 MCP/SSE 地址，并可自定义请求头 JSON；服务列表显示每个服务的连接方式。
- 远程地址须为 HTTPS，本机 `localhost`/`127.0.0.1` 可用 HTTP；请求头最多 16 项，不能覆盖 Host、Accept、Content-Type 等保留字段。
- 工具调用仍由宿主执行并逐次确认，最多 8 次调用、5 个模型回合。

### 设置与界面

- 设置页分为「模型供应商」与「MCP 服务」两页，工具栏可切换当前页。
- 设置页内联错误提示（`role="alert"`），添加服务失败不再静默。
- 工具栏支持换行、设置页改为整页滚动，密集配置项不再挤压对话区域。

### 兼容性

- 需要支持插件网关 API v3 的 issh 客户端（新增 `mcp.remote` 权限）；旧客户端会在加载前拒绝本插件。
- 插件包不内置模型凭据、MCP 服务程序或代理配置。
